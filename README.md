# Daniel Paul O'Donnell Curriculum Vitae
This is where I keep my new tex version of my CV. It is build on the basis of the modernCV template.

Version numbers are n.n.n where N1 = Changes to design or organisation of CV, N2 = New item (since last redesign/change), N3 = correction/addition/edit to existing item (new URL, typos, etc.)

local note: use @make cv@ to run the tex interpreter
